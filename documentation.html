Documentation

This virtual museum presents selected milestones from the Versace legacy as an interactive archive. Users can navigate through multiple themes and curated exhibition paths.

Main sections include Home, Map, Collection, and About Us. Each collection item provides context and story-focused descriptions for different visitor profiles.

The website includes four graphical themes that allow the same exhibition content to be experienced through different visual languages. The theme switch is integrated directly into the interface and is available across the site, with four selectable options represented by icons.

The Baroque theme is the default visual style of the exhibition. Its design is inspired by Rococo and Baroque aesthetics, using warm cream backgrounds, brown text, gold accents, decorative textures, and elegant serif typography. The visual effect is refined and museum-like, creating a sense of historical richness and ornamentation that fits the subject of fashion heritage. The use of soft gradients, ornamental side decorations, and translucent content panels reinforces an atmosphere of luxury and classical beauty.

The Art Deco theme uses a darker and more geometric visual language. It combines black and gold tones, strong contrast, symmetrical decorative framing, and display-style typography. This theme feels glamorous, theatrical, and sophisticated, echoing the polished luxury often associated with high fashion. Compared to the default theme, it is more dramatic and structured, with sharper visual hierarchy and a more formal, stylized appearance.

The 90s theme deliberately references the look of early web portals and forum interfaces. Its design uses simple system-style fonts, purple sidebars, black borders, flat white content blocks, and compact text proportions. This creates a nostalgic digital aesthetic that contrasts with the elegance of the exhibition content. The theme is intentionally more playful and retro, highlighting a period-specific internet visual culture rather than traditional museum design.

The Futuristic theme reimagines the exhibition in a cyber-inspired style. It uses a dark background with neon blue, violet, and magenta accents, glowing effects, transparent glass-like panels, and modern techno-inspired typography. The layered gradients and grid overlays give the interface a digital, immersive quality. This theme presents the exhibition as something innovative and forward-looking, emphasizing experimentation and contemporary visual culture.

Together, these four themes were designed to show how the same cultural content can be framed through different aesthetic choices. Instead of changing the structure of the site, the project changes color, typography, texture, and decorative language, allowing users to explore the exhibition through multiple visual interpretations while preserving the same navigation and content architecture.
